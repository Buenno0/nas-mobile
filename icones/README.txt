Ozymandias — ícone de app iOS
================================

svg/  AppIcon-{light,dark,tinted}-1024.svg  quadrado full-bleed (o iOS aplica a máscara)
      Mark-{light,dark,tinted}.svg          apenas o símbolo, fundo transparente
png/  AppIcon-{variante}-{1024,180,120,87,60,40}.png

Xcode: Assets.xcassets > AppIcon > slots Any / Dark / Tinted.
Use os PNG 1024 (ou o SVG single-size) em cada slot.
A variante tinted é monocromática: o sistema aplica o matiz do usuário.
